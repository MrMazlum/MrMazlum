## Projects

### Tortul — Life Management App
> Android · Flutter · Firebase · [Google Play](https://play.google.com/store/apps/details?id=com.mazlum.tortul&pcampaignid=web_share)

A personal productivity app that tracks health, finances, reading, and schedules — all in one place. Features a full gamification layer with XP, 18 levels, streak shields, cosmetics, weekly missions, and a social friends system with duels and leaderboards.

- **18 levels** across 6 tiers (Ash → Crimson), XP system with daily caps
- **Gamified social layer** — friends, weekly XP duels, global leaderboard, shareable achievement cards
- **Finance tab** — account management, CC bill tracking, spending buckets, pie chart overview
- **Health tab** — daily logs with Health Connect integration
- **11 locales** (EN, TR, DE, ES, FR, IT, HI, PL, PT, RU, ZH)
- **97 unit tests**, Firestore security rules hardened, custom particle animations
- Currently on open test track — v1.0.0+14
